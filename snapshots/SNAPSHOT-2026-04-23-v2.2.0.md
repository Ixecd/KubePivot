## 核心变更

### 1. KpExecutor 统一子进程执行层（internal/executor/executor.go）

新增模块解决 scratch 容器 PATH 查找失败问题：

```go
func resolveBin(name string) string {
    abs := "/usr/local/bin/" + name
    if _, err := exec.LookPath(abs); err == nil {
        return abs  // scratch 容器
    }
    if p, err := exec.LookPath(name); err == nil {
        return p    // 本机（支持 Homebrew）
    }
    return name
}
```

单例 + 信号量限流 sem=5，四个核心接口：Kubectl / Helm / Generic / CmdKubectl。

### 2. 全量替换 exec.Command

**controller 包**（scratch 容器，必改）：
- `internal/controller/resources.go` DetectResourceExists
- `internal/controller/heal.go` 所有 kubectl/helm 调用
- `internal/controller/drift_sync.go` detectDrift / forceSync
- `internal/controller/sandbox_gc.go` cleanExpiredSandbox

**cmd/kp 包**（兼容层）：
- `cmd/kp/runner.go` runOutput 识别 kubectl/helm 前缀后走 executor
- `cmd/kp/deploy.go` ensureSecret 改用 CmdKubectl + --context

本机 CLI 保留裸 exec.Command（version / doctor / plugin / policy / secret / drift）。

### 3. etcd key 破坏性升级

```
dtk/<project>/<ns>/state  →  kubepivot/<project>/<ns>/state
```

涉及 `internal/state/store.go` / `state.go` / 3 个测试 / 设计文档。

### 4. RBAC 权限补全

**核心修复：secrets 完整 CRUD**

根因：helm v3 将 release state 存在 Secret 里（type=helm.sh/release.v1），rollback 需要完整 CRUD 权限。旧 RBAC 只给了 get/list/watch。

补全：deployments/statefulsets/services/configmaps/namespaces/networking/serviceaccounts/roles/rolebindings 全部 CRUD + apiextensions/CRD read-only。

### 5. Dockerfile 升级

`build/docker/controller/Dockerfile`：

- Go 1.26（消除 1.25.x stdlib HIGH CVE）
- helm v3.17.1 硬编码（避免 GitHub API 限流 404）
- kubectl 动态获取 dl.k8s.io/stable.txt
- scratch runtime + CA 证书 + /tmp/.keep
- upx 只压 kp，不压 kubectl/helm
- 多架构 manifest list（amd64 + arm64），tag 不带架构后缀

### 6. 细节修正

- `syncStateRunning` 不再强行推 IDLE → RUNNING（尊重状态机契约）
- `forceUnlockIfSandboxState` 删除无用参数（project / namespace）
- Controller 启动日志确认 etcd key 为 `kubepivot/` 前缀

## 下个版本预告（v2.3.0）

**架构级跃迁：全局单一 HA controller**

```
现在（每项目独立 controller）
├── feelings-server/kubepivot-controller（3 副本）
├── web3-blitz/kubepivot-controller（3 副本）
└── ... 每项目都 3 个 pod，资源冗余

v2.3.0（集群单一 controller）
└── kubepivot-system/kubepivot-controller（3 副本，全局 HA）
    通过 kubepivot.io/managed=true label/annotation 发现所有项目
    → N 项目场景下节省 3(N-1) 个 pod
```

其他 v2.3.0 目标：

- Controller 启动从 etcd 恢复状态机（根治 IDLE → RUNNING）
- helm --history-max 限制 revision 堆积
- rbac.yaml 重构为 embedded template file
- Dockerfile 多架构 GitHub API 限流容错
