  StatefulSet Pod: evict myapp-0 → recreate myapp-0 → name match ✅
  Deployment Pod:  evict myapp-7d9f8-abcde → recreate myapp-7d9f8-fghij → 改名失配 ❌

  结果: Deployment Pod 迁移 hint 丢失，回弹到源节点，迁移引擎空转。

  双 key 存储:
    migrationTargetHints["ns/pod-name"] = targetNode       (name-based)
    migrationTargetHints["ns/label:app-value"] = targetNode (label-based)

  双路查找 (webhook handleMutate):
    1. PopMigrationTargetHint(ns, name)          name primary
    2. PopMigrationTargetHintByLabel(ns, label)  label fallback
    3. scheduler.AssignPod()                     正常调度

  SetMigrationTargetHintWithLabel(ns, name, appLabel, node):
    同时写两个 key。appLabel 为空时仅写 name key（向后兼容）。
