feat(sealed-secrets): v2.8 G (G-Level1) — kp secret seal + kubeseal CLI wrapper

ROADMAP §2.3 G 节 sealed-secrets 集成. G-Level1 最小可行交付.

K8s Secret 默认只是 base64 编码 (不是加密!), 任何 git 仓库不能放 Secret YAML.
sealed-secrets (Bitnami) 用集群公钥加密 → SealedSecret 即使泄露也无法解密
(私钥永远不出集群). apply 后 controller 自动解密成普通 Secret.

跟 KubePivot GitOps 哲学完全一致: kp secret seal → SealedSecret YAML
→ git commit → kp deploy → controller 自动解密.

实施流程 (跟 sealed-secrets 官方推荐 100% 一致):

  Step 1: kubectl create secret generic <name> --from-literal=K=V \
              --namespace <ns> --dry-run=client -o yaml
  → 输出普通 K8s Secret YAML (base64 编码, 不加密)

  Step 2: stdin pipe 给 kubeseal --scope <s> -o yaml
  → 输出 SealedSecret YAML (集群公钥加密, 私钥永不出集群)

  Step 3: 用户 git commit configs/sealed/<name>.yaml
  Step 4: kp deploy → kubectl apply
  Step 5: sealed-secrets-controller 自动用集群私钥解密成普通 Secret
