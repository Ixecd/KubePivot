设计核心 (5 个对齐原则):

  Q-B.8=A 命令注册模式: 对齐既有 switch-case 风格
    cmd/kp/main.go: case "sizing": runSizing(os.Args[2:])
    ✓ 与 deploy/scan/supply-chain 等命令风格 100% 一致
    ✓ 用户心智统一: kp <command> <subcommand> --flag=value
    
  Q-B.9=A 参数解析: 复用 flag.NewFlagSet + ExitOnError
    --pod (required), --namespace (default: default), --profile (web/batch/db/default)
    --output (stdout/file), --samples (2-10), --interval (2s-10s)
    ✓ 对齐 runDeploy/runScan 参数风格
    ✓ 错误处理: fmt.Fprintf(os.Stderr) + osExitFunc(1)
    
  Q-B.10=A 输出风格: P.Start/Done/Fail + fmt.Fprintf(os.Stderr)
    成功: P.Info("✓", "Sizing patch written to xxx") + 输出 patch YAML
    失败: P.Fail("✗ ...") + fmt.Fprintf(os.Stderr, "  Details: %v\n", err)
    ✓ 与既有命令终端体验一致
    ✓ 避免再用不存在的 P.Warn/P.Error
    
  Q-B.11=A 资源解析: 新增 parseMemoryResource (不污染 planner.go)
    支持: "512Mi" → 536870912, "1Gi" → 1073741824, "256Ki" → 262144
    ✓ 复用 metrics.Quantity 解析逻辑，不复造轮子
    ✓ 独立于 planner.go，避免交叉污染
    
  Q-B.12=A 采样封装: samplePodMetrics 内联 (Level1 最小化)
    调用 metrics.MetricsClient.GetPodMetrics N 次，间隔可配
    ✓ 避免跨包依赖复杂化，Level2 再提取到 internal/sizing/sample.go
    ✓ 容忍单次采样失败，保证鲁棒性
