reconnect.go 实现 Q7=C "指数退避 + jitter=0.2"：
  - ReconnectPolicy struct (5 个字段 + rng 注入测试用)
  - DefaultReconnectPolicy: 1s/30s/2.0/0.2/0(unlimited)
  - NextBackoff(attempt): 指数增长 + 封顶 + 对称 jitter ±20%
  - 处理 attempt 溢出 / 负值
  - ShouldGiveUp() 判定（MaxAttempts=0 永不放弃）

  退避序列示例 (jitter=0.2)：
    attempt 1: 1s   ± 0.2s
    attempt 2: 2s   ± 0.4s
    attempt 5: 16s  ± 3.2s
    attempt 6+: 30s ± 6s (封顶)

resync.go 实现 Q8=C "按资源类型差异化"：
  - 4 个 ResyncPeriod 常量:
    High      (10min)  pods / events
    Medium    (30min)  deployments / statefulsets / jobs / ...
    Low       (60min)  services / configmaps / ingresses / ...
    VeryLow  (120min)  namespaces / nodes / storageclasses / ...
  - DefaultResyncPeriod() 主入口
  - normalizeResource: 大小写不敏感 + 单复数容错（pod → pods）
  - 未知资源兜底 Medium 30min
