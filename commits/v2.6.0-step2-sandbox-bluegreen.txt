feat(sandbox): v2.6.0 P0 Step 2 — Sandbox 蓝绿流量切换接入

承接 commit 786b59d (Step 1) 完成的 internal/route 包，本次将其
接入 kp sandbox commit 命令，实现完整蓝绿部署链路。

接入点设计：
  - 不动状态机（state.go 不改）
  - 在 sandbox.go COMMITTING 阶段的 commitOK 检查后插入流量切换
  - 失败复用现有 runSandboxRestore（与 v1.8.0 风格一致）

完整流程：
  LOCKED → SNAPSHOTTING → SIMULATING → COMMITTING:
    Step 1: runSandboxCommit (v1.8.0 既有，跑 helm + migrate)
    Step 2: runBlueGreenSwitch (v2.6 新增) ← 本次接入点
  → RUNNING  /  失败 → RESTORING → IDLE

resources.yaml v2.6 schema:
  traffic:
    kind: Ingress              # 可选，省略自动检测
    strategy: blue-green       # v2.6.0 仅蓝绿
    refs:
      name: wallet-ingress
    routes:
      - service: wallet-service-blue
        weight: 100
      - service: wallet-service-green
        weight: 0
    validation:
      podReadyTimeoutSec: 60   # 默认 60s

设计原则核对：
  ✓ 不引入 client-go：通过 route 包间接走 executor.GetExecutor()
  ✓ 不动 state.go：COMMITTING 内顺序两步完成
  ✓ 失败统一 RESTORING：复用现有 runSandboxRestore
  ✓ 默认沉默：不配置 traffic 字段就不打"跳过"日志
  ✓ "只保护，不越权"：完整保留用户字段（route 包 buildXxxFromRoutes）
