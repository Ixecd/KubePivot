feat(eventstream): shard listener — ForceResync + OnShardChanged 接线，盲区归零

v3.3 高优：shard 翻转时 informer 立即 force resync，不再依赖 30min 周期性兜底。
Informer 接口加 ForceResync()，InformerPool 加 ForceResyncAll()，global.go 接线。
防御性 cancel 竞速保护 + force_resync_total 指标。

ForceResync 机制
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Informer.ForceResync():
    ├─ forceResyncTotal.Add(1)         计数器
    ├─ forceResync <- {} (cap=1, non-blocking)  合并重复触发
    └─ watchCancel()                   中断当前 HTTP watch 长连接

  runWatchLoop 三处 forceResync 处理:
    1. top-of-loop:    select { case <-forceResync: 防御性 cancel → relist → continue }
    2. during backoff: select { case <-forceResync: relist → attempt=0 }
    3. doWatch 返回后:  errors.Is(err, context.Canceled) → continue (跳过退避)

  防御性 cancel (top-of-loop):
    防止竞速 — forceResync 信号到达时 watch 可能在信号处理前重新建立
    watchCancelMu.Lock() + if watchCancel != nil { watchCancel() }

  InformerPool.ForceResyncAll():
    RLock informers map → 遍历 informer.ForceResync()
    无 informer 启动时 silent no-op

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
global.go 接线
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  OnShardChanged 回调内:
    len(added) > 0 → informerPool.ForceResyncAll()
    同步执行（非阻塞：channel send + context cancel），不依赖 2s 延迟 goroutine

  触发链:
    MultiLeaseManager.reconcileShards() → go callback(added, removed)
      → OnShardChanged → ForceResyncAll() → 每个 informer.ForceResync()
        → watchCancel() → runWatchLoop 中断 → forceResync select → relist

  盲区: 30min resync ticker 兜底 → 0 (shard flip 后 <1s relist)
