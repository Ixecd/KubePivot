perf(scheduler): v3.2 规模化三刀 — Reservoir采样 O(5k) + NodeShard PoolUtil + Lease Fencer

规模化路径落地：100k pods 碎片率 1886ms→1046ms (1.8x)，pool-level err <7%。
采样 O(1k)→O(5k) 恒定，瓶颈从遍历转移至 map/group/sort。

规模化三刀
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Reservoir Sampling (pool.go):
    samplePods(pods, maxSamples) — 标准 reservoir algorithm
    sampleCount(nPods, nNodes) → max(5k, 5×nNodes)
    ComputePoolUtilizationSampled: auto-triggers when pods > sampleCount
    100k pods + 2k nodes → 10k samples (10%), O(10k) vs O(100k)

  Node-shard PoolUtil (pool.go):
    NodeShardedPoolUtil — 32-way node-hash partition
    Pre-summed per-shard, merge O(32)
    Avoids cross-shard ListAll merge storm

  Lease Fencer OOB (migration_manager.go):
    DefaultLeaseFencer() — kubectl create lease, OOB isolation
    lease acquire fail → old Pod still holds → migration blocked
    gRPC stub v3.4
