2. 核心技术决策
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  HTTPS 全链路: crypto/x509 自签 CA, 8 个 etcd TLS flag, 0 外部依赖
  方案 B CA 分发: Controller install 预生成 Secret → Pod 只读不写
  PodIndex 门禁: 只有 Pod-0 可 ColdStart, 防止脑裂
  isLeader 修正: RaftTerm>0 → Leader==MemberId (精确比较)
  Learner 幂等: JoinAsLearner Step 0 查 getMemberRole, Voter 跳过
  PromoteLearner 幂等: promote 前查角色, 已 Voter 则跳过
  自适应轮询: lag<1000→200ms, lag≥1000→2s, 稳定窗口动态缩放
  safeDefrag: Leader 跳过 → Follower 做 → move-leader 转移

3. 六项鲁棒性补丁
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  CA 轮转幂等: Secret 已存在且未 force-rotate → 跳过
  peerHasData: 区分 kubectl exec 失败(不可达) vs 文件不存在(无数据)
  Defrag 预检: clusterHealthy() 只剩 2/3 节点时跳过
  Uninstall 清理提示: hostPath 数据需手动清理 /data/etcd
  Base64 TrimSpace: kubectl jsonpath 可能带不可见字符
  证书权限: server-key.pem 0600
