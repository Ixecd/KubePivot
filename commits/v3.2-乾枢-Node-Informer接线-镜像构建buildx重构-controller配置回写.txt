fix(controller-build): Node Informer 接线 + buildx 构建重构 + controller 配置回写

Node Informer → NodeCacheBridge → NodeCache 自动填充，修复 Rescheduler
"informer cache not ready" 每5min报错。镜像构建从5步流程简化为 buildx --push
一条命令。kp controller update --apply 自动回写 configs/system.yaml。

镜像构建 buildx 重构
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  旧: go.build → docker build (per arch) → docker push (per arch)
       → docker manifest create → annotate → push (5步, 常断)
  新: docker buildx build --platform linux/amd64,linux/arm64 --push
       (1步, 自动manifest)

  image.mk:
    image.build.multiarch: buildx build (不走 go.build 预编译)
    image.push.multiarch: buildx build --push
    image.manifest.push: 废弃 → 指引用户用 push.multiarch
    --no-cache 默认启用 (防 Docker layer 缓存污染)
    构建上下文改为 ROOT_DIR (修复 COPY go.mod 失败)

  golang.mk:
    controller → kp 映射 (go.build 能编译 controller 镜像)

  Makefile:
    push.manifest: 独立 manifest 重试 (网络闪断恢复)
    push.manifest 文档化为 "Retry push"
