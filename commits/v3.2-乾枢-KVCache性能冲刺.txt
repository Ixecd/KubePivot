perf(eventstream): v3.2 KVCache 性能冲刺 — Delta buffer + Sharded + merge-on-read + RV CAS

v3.2 KVCache 性能冲刺 + 命门修复。9 项优化，5 文件变更，19 包全量 test 通过。

核心改动
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Delta buffer (Put O(1)):
    Put 写 delta map (~100ns) 而非全量 CoW (387μs)
    merge-on-read: ListAll/ListByNode 非阻塞合并 delta+snapshot
    delta 超阈(200)异步 go FlushDelta()，防惊群
    RV CAS: Put 拒绝 event.RV < current.RV (Watch 乱序 / 410 Gone)

  ShardedPodCache (16-way power-of-2):
    按 namespace FNV hash 分片，各分片独立 delta + deltaMu
    PutBulk 按 ns 分组并发写入，写并发 N 倍
    ListAll merge-on-read 跨分片合并

  Generation + PoolUtilCache:
    PodCache.Generation() 单调 atomic.Int64，写入 +1
    PoolUtilCache.GetOrCompute(gen): 无变化返回缓存 (~100ns vs 1ms)

  poolFragmentRate 复用 usageMap:
    外层建一次 usageMap，6 次内部调用复用
    7×O(Np) → 1×O(Np)

  NodeCache ListAll zero-copy:
    nodeSnapshot.list 预缓存，ListAll 直接返回 slice 指针

  PodEntry/NodeEntry.RV (etcd ResourceVersion):
    双 Cache (Skeleton↔PodEntry) 桥接字段，Put CAS 防旧覆盖

  ready=false 默认:
    PutBulk 前 cache 未就绪 → InformerAdapter 走 ErrCacheNotReady fallback
    ShardedPodCache 空分片手动 ready=true

  Makefile bench + prune gate:
    bench.kp / bench.baseline / bench.regression
    benchmark/README.md: Real YAML 工具链 + 退步阈值

  Cold→Warm 测试:
    TestInformerAdapter_ColdToWarm: 冷启动→ErrCacheNotReady→预热→正常

性能特征 (v3.2.1)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Put:         O(1) delta write + RV CAS, ~120ns, 0 alloc
  PutBulk:     O(N) CoW, ~657μs @ 5k
  Delete:      O(1) delta tombstone, ~100ns, 0 alloc
  Get:         O(1) lock-free, 0 alloc, 24ns
  ListAll:     delta empty → O(1) pre-built slice (0 alloc)
               delta non-empty → O(N) merge-on-read
               delta >200 → async CoW flush
  ListByNode:  O(K) byNode (delta empty) / O(K+Nd) merge (delta non-empty)
  FlushDelta:  O(N) CoW snapshot rebuild
  Generation:  O(1) atomic load
