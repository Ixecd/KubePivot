feat(etcdmanager): wire compact/defrag intervals to config system

EtcdManager 类型 int→time.Duration，NewEtcdManagerFromConfig() 接线 config，
controller.Start() 自动启动 etcd 维护循环。硬编码 1h/24h → config.Load() 驱动。

  EtcdManager:
    CompactHour int    → CompactInterval time.Duration
    DefragHour  int    → DefragInterval  time.Duration

  compactLoop:
    time.Duration(m.CompactHour) * time.Hour → m.CompactInterval

  NewEtcdManagerFromConfig(podIndex, totalPods, namespace, compactInterval, defragInterval):
    零值自动降级：compact<0 → 1h, defrag<0 → 24h
    向后兼容 DefaultEtcdManager 保留（测试/脚本用）

  controller.Start():
    global mode → go startEtcdMaintenance(ctx) → NewEtcdManagerFromConfig()
    POD_INDEX 从 KUBEPIVOT_POD_INDEX 环境变量读取
    replicas 从 config.Controller.Replicas 读取
    compact/defrag 间隔从 config.Etcd 读取

  不启动条件:
    per-project 模式（无 etcd 集群）
    config 字段空 → 降级默认值 (1h/24h)
