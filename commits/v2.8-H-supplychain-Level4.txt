实施流程 (跟 Sigstore/OCI 官方推荐 100% 一致):

  Step 1: 配置 keyless 验证 (三选一或组合):
    - resources.yaml: supply-chain.signing.keyless: { identity: ci@org.com, issuer: https://accounts.google.com }
    - project.env: SUPPLY_CHAIN_OIDC_IDENTITY / ISSUER
    - CI/CD: KP_SUPPLY_CHAIN_OIDC_* 环境变量注入

  Step 2: 用户运行部署:
    kp deploy --components configs/components.yaml

  Step 3: 内部流程 (签名验证):
    → 解析策略配置, 合并优先级
    → 如果 signing.keyless 启用: 调用 cosign verify --certificate-identity <id> --certificate-oidc-issuer <iss>
    → 解析 Fulcio 证书链 + Rekor 透明日志验证
    → 缓存结果 (5min TTL), 避免重复验证

  Step 4: 用户生成 + 上传 SBOM:
    kp supply-chain sbom registry.io/app:v1.2.3 --push
    → 内部: syft registry.io/app:v1.2.3 -o cyclonedx-json -q
    → 派生目标: registry.io/sboms/app:v1.2.3.sbom.cyclonedx-json
    → 调用: oras push <target> --artifact-type application/vnd.cyclonedx+json - < sbom.json
    → 输出: ✓ SBOM uploaded to registry.io/sboms/app:v1.2.3.sbom.cyclonedx-json

  Step 5: 后续 pipeline 自动关联:
    - OCI referrers API: 查询镜像关联的 SBOM artifacts
    - dependency-track: 导入 CycloneDX SBOM, 自动关联 CVE/许可证
    - 审计日志: 谁/何时/何镜像/何签名/何 SBOM → 可追溯
