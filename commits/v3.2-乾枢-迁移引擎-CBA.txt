  MigrationLabel 索引:
    - MigrationLabelKey = "kubepivot.io/migration-active" (真 K8s label)
    - MigrationLabelSelector() 返回 label 名，可用 LabelSelector API 过滤
    - MigrationLabels() / MigrationCleanupLabels() 配套
    - 替代原 annotation key 冒充 label selector 的 bug

  Dual-Path Paused+Retry:
    - PhasePaused: Stateful 迁移超时不直接 Failed，进入 Paused 等 backoff
    - Migration.RetryCount + MigrationManager.maxRetries (default 3)
    - reconcilePaused: backoff (30s) 后自动重试 WaitingForReady
    - Stateless 迁移超时仍走 Failed（原行为不变）

  SignalProtocol fallback chain:
    - FencingConfig.FallbackChain(): AnnotationWatch → Webhook → SIGTERM
    - FencingConfig.NextProtocol(): 指定当前协议，返回下一回退

  一致性哈希 HashRing (替代 hash%len):
    - 真一致性哈希环：每个 Pod 40 个虚拟节点，FNV32 hash 分布
    - NewHashRing / GetPod / DiffCells (计算漂移)
    - 4→3 Pod 时仅 ~25% Cell 漂移（vs 原 100% 全量漂移）
    - MapCellsToPods 内部使用 HashRing

  Rehydrate 重启恢复:
    - MigrationManager.Rehydrate(pods) 从 Pod annotation 恢复内存状态
    - PodInfo 新增 Annotations 字段
    - 幂等：已有 migration 不覆盖

  DryRun 真隔离:
    - Reconcile 入口 clone migrations map → 在克隆上操作
    - 真实状态完全不受影响
    - 替代原 Dead Code (DryRun bool 从不检查)

  time.Parse 错误处理:
    - ParseMigrationFromAnnotations 检查 err
    - 损坏时间戳 fallback 到 time.Now()（避免 Year 1 零值 → 瞬间判定超时）

  Fencing HardTimeout:
    - FencingConfig.HardTimeout (default 60min)
    - FencingState.ShouldForceRelease(cfg): Draining/Paused 超硬超时 → 强制释放
    - 损坏时间戳保守返回 true（不永久锁 Cell）
