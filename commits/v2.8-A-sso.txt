OAuth2 流程实现细节:

  PKCE (RFC 7636):
    code_verifier  = base64url(32 random bytes)  → 43 字符
    code_challenge = base64url(SHA256(verifier))
  
  Callback server:
    起本地 HTTP server 监听 localhost:18888/callback
    state 校验 (CSRF 防护)
    成功返回友好 HTML 页 ("✅ 关闭此页回终端")
    server 通过 ctx Shutdown 干净退出
  
  跨平台浏览器打开:
    macOS:   open <url>
    Linux:   xdg-open <url>
    Windows: rundll32 url.dll,FileProtocolHandler
